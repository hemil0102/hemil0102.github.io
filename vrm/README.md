파일은 그대로 두고(개조 금지) 표정·본 제어만 런타임에서 수행합니다.

## 다른 모델로 바꾸려면
1. `.vrm` 파일을 이 폴더에 넣습니다.
2. Jerry 페이지 → 설정 → "3D 아바타 URL" 에 `vrm/파일명.vrm` 입력 후 저장.
3. 기본 3D 얼굴로 되돌리려면 같은 칸에 `none` 을 입력합니다.
